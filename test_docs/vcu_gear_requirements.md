# VCU 档位管理功能需求文档（示例）

## 1. 功能概述
本文档描述整车控制器（VCU）档位管理功能的需求规范，覆盖 P/R/N/D 四个挡位的切换逻辑、DriveReady 控制、换挡失败提示等核心功能。

## 2. 功能需求

### 2.1 P挡至D挡切换
- 车辆静止且制动踏板踩下时，P挡可切换至D挡
- 切换后进入DriveReady状态，驱动扭矩准备就绪
- 切换时间不超过500ms

### 2.2 D挡至P挡切换
- 车速低于3km/h且制动踏板踩下时，D挡可切换至P挡
- 切换后驱动系统断开，P挡锁止机构engage
- 切换完成后车辆进入驻车状态

### 2.3 R挡切换条件
- 车辆静止且制动踏板踩下时，可从P挡或N挡切换至R挡
- R挡时倒车灯点亮，倒车影像激活
- R挡时驱动扭矩方向为负（倒车方向）

### 2.4 N挡滑行保护
- N挡时驱动扭矩为零
- 车速超过10km/h时禁止切换至P挡或R挡
- N挡滑行时能量回收功能禁用

### 2.5 DriveReady使能逻辑
- D挡且制动踏板释放后，DriveReady使能
- DriveReady使能后驱动扭矩准备就绪
- DriveReady禁止时驱动扭矩为零

### 2.6 换挡失败提示
- 不满足换挡条件时，仪表闪烁当前挡位指示灯
- 闪烁持续3秒后停止
- 同时发出短促提示音

### 2.7 P挡闪烁控制
- 车辆未READY且挡位为P时，P挡指示灯以1Hz频率闪烁
- 车辆READY后P挡指示灯常亮
- 车辆下电后P挡指示灯熄灭

### 2.8 组合开关控制
- 拨杆开关信号通过CAN总线传输至VCU
- VCU解析拨杆位置并执行换挡逻辑
- 组合操作需在200ms内完成识别

### 2.9 插枪挡位互锁
- 充电枪插入时，挡位锁定P挡
- 充电过程中禁止切换至其他挡位
- 充电枪拔出后恢复挡位切换功能

### 2.10 上下电挡位控制
- 上电默认挡位为P挡
- 下电时保持P挡锁止状态
- 紧急下电时VCU强制切至P挡并锁止

## 3. 接口需求
- 挡位传感器信号：PWM信号，频率100Hz
- 制动踏板信号：数字量，0=未踩/1=已踩
- 车速信号：CAN报文，分辨率0.1km/h
- 换挡执行器：CAN控制信号

## 4. 性能需求
- 挡位切换响应时间 ≤ 500ms
- DriveReady使能延迟 ≤ 200ms
- 换挡失败提示延迟 ≤ 100ms
