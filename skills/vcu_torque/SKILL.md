# VCU 扭矩管理测试用例生成技能

## 技能描述
基于汽车 VCU 扭矩管理功能规范，自动生成符合平台化测试用例库标准的 S0/S1/S2/S3/S4 五级测试用例。

## 适用场景
- 基于扭矩管理需求文档生成测试用例
- 补充测试用例库
- 平台化测试用例复用

## 功能覆盖

### 蠕行功能
- 蠕行扭矩请求逻辑
- 蠕行使能/禁止条件
- 蠕行扭矩大小与车速关系
- 蠕行退出条件

### 滑行能量回收
- 滑行回收触发条件（油门松开）
- 回收扭矩梯度控制
- 回收扭矩与车速/SOC关系
- 滑行回收退出条件

### 减速缓行模式
- 减速缓行进入条件
- 减速扭矩请求逻辑
- 缓行模式与蠕行模式切换
- 减速缓行退出条件

### 制动能量回收 CRBS
- CRBS 使能条件
- 制动踏板与回收扭矩映射
- CRBS 与摩擦制动协调
- CRBS 退出与故障处理

### 扭矩限制
- 最大驱动扭矩限制
- 最大制动扭矩限制
- 扭矩变化率限制
- 过温/过流降扭保护

### 跨域扭矩交互
- 扭矩与档位联动
- 扭矩与车速联动
- 扭矩与 ESP/ABS 交互
- 扭矩与 BMS 交互

## 用例分级标准

| 级别 | 定义 | 覆盖率要求 |
|------|------|-----------|
| S0 | 基础功能验证 | 100% |
| S1 | 正常流程变体 | ≥80% |
| S2 | 边界异常 | ≥60% |
| S3 | 故障注入 | ≥40% |
| S4 | 跨域交互 | ≥30% |

  }
