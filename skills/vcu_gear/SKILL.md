# VCU 档位管理测试用例生成技能

## 技能描述
基于汽车 VCU（整车控制器）档位管理功能规范，自动生成符合平台化测试用例库标准的 S0/S1/S2/S3 四级测试用例。

## 适用场景
- 基于档位管理需求文档生成测试用例
- 补充测试用例库
- 平台化测试用例复用

## 功能覆盖

### 档位切换逻辑
- P → R / N / D 切换条件与时序
- R → P / N / D 切换条件与时序
- N → P / R / D 切换条件与时序
- D → P / R / N 切换条件与时序
- 非法档位切换拒绝逻辑

### DriveReady 控制
- DriveReady 使能/禁止条件
- DriveReady 状态转移
- DriveReady 与档位联动

### 换挡失败提示
- 换挡失败触发条件
- 失败提示方式（仪表/声音/指示灯）
- 失败恢复逻辑

### P 挡闪烁控制
- P 挡闪烁触发条件
- 闪烁频率与模式
- 闪烁停止条件

### 组合开关控制
- 拨杆开关信号解析
- 按键开关信号解析
- 组合操作时序

### 插枪挡位控制
- 充电枪插入/拔出时挡位逻辑
- 充电状态与挡位互锁

### 上下电挡位控制
- 上电默认挡位
- 下电挡位保持/释放
- 紧急下电挡位处理

## 用例分级标准

| 级别 | 定义 | 覆盖率要求 |
|------|------|-----------|
| S0 | 基础功能验证（正向基本流程） | 100% |
| S1 | 正常流程变体（边界值/组合） | ≥80% |
| S2 | 边界异常（非法输入/异常时序） | ≥60% |
| S3 | 故障注入（信号丢失/通信中断） | ≥40% |

```json
    "id": "TC-GEAR-S0-001",
    "title": "P挡至D挡正常切换",
    "level": "S0",
    "precondition": "车辆静止，制动踏板踩下，当前挡位P",
    "steps": [
      "1. 启动车辆，确认仪表显示P挡",
      "2. 踩下制动踏板",
      "3. 拨动换挡杆至D挡位置"
    ],
    "expected": "仪表显示D挡，车辆进入DriveReady状态，驱动扭矩准备就绪"
  }
]
```
